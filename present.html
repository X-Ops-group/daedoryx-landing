06 / SECURITY DOMAIN TWO — THE AI WORKFORCE

Agents can act.
Only within their authority.

Every autonomous agent is a non-human software actor. Secure its identity, delegated permissions, model context, tool calls, data movement and full execution lifecycle.

01 / IDENTITYNon-human identityIndividual agent identity, service principals and bounded credentials
02 / AUTHORIZATIONLeast privilegeTask-scoped permissions, policy decisions and approval gates
03 / CONTEXTInjection resistanceSeparate untrusted data from privileged instructions
04 / TOOLSMCP / A2A securityAuthorized tool calls, peer identity and restricted execution
05 / DATAEgress boundariesRestrict access, data movement and external destinations
06 / RESPONSETrace & revokeReviewable event trails, containment and credential revocation
AGENT SECURITYThe enterprise must control what an agent is allowed to do — not only what it is allowed to say.

Reference security design and proposed control families. Control effectiveness and production readiness require implementation evidence and independent testing.
