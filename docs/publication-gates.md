# DAEDORYX Publication Gates

This repository is public, but the site is a **preview**. Its robots.txt disallows search indexing, and launch approval is not implied.

Before commercial publication:
- Verify intellectual-property ownership and that no HOLOS/other proprietary internals are exposed.
- Verify the legal operator, contact method, terms, and privacy policy.
- Confirm which platform functions actually exist vs. only architectural direction.
- Confirm cloud, hybrid, and private deployment availability.
- Validate website accessibility, browser behavior, and performance in a real hosted environment.
- Integrate a secure backend/CRM intake with data minimization, spam protection, consent notices, and tested delivery before claiming functional lead capture.
- Confirm responsive and event-mode visual QA on physical devices.
- Set canonical domain, SEO/social asset, and robots policy.
- Configure TLS, CSP, and security headers at the chosen hosting provider.
- Obtain an independent PR review. No agent should self-approve its own implementation.

**The scenario calculator is an explanatory model only**, not published evidence of DAEDORYX or customer outcomes.
